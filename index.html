Evaluación Docente UDM

Sistema web para gestionar las evaluaciones docentes de la universidad: los alumnos evalúan a sus profesores y la administración consulta resultados y genera reportes por campus, periodo y grupo.

  • 5 roles con permisos propios: super administrador, administrador, administrativo, docente y alumno
  • Editor de evaluaciones con preguntas y escalas de calificación configurables
  • Catálogos de campus, niveles, periodos, grupos y materias, con carga masiva desde Excel
  • Resultados y reportes en PDF; recuperación de cuenta por correo y respaldos de la base de datos
  • Pruebas con pytest en GitHub Actions y despliegue con Docker y Gunicorn en Railway

Automatización · API + workerEn desarrollo

ChambaBot

Busca vacantes en APIs de empleo y en las alertas por correo de Computrabajo, Indeed y LinkedIn, las filtra, las califica con IA contra mi perfil y me ayuda a postularme y dar seguimiento.

  • Monolito modular hexagonal (ports & adapters) con dos procesos, api y worker, sobre la misma imagen
  • Fastify + Zod, PostgreSQL con Drizzle ORM, colas y cron con Redis + BullMQ
  • Calificación con IA local (Ollama, qwen3.5:4b); autenticación con JWT + argon2
  • Casi 500 tests con Vitest y Testcontainers (Postgres y Redis reales), cobertura por archivo y reglas de lint que protegen las capas
  • Git Flow, GitHub Actions (lint, tipos, tests, build), imagen en GHCR, releases con versionado semántico y deploy automático a Dokploy por webhook
  • Planeado: app móvil y avisos por Telegram
